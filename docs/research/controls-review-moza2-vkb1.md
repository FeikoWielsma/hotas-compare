## Remaining schema/data limits

The hat schema defaults omitted direction count to 4, and the toggle schema defaults omitted positions to 2. Unknown-way hats and unknown-position toggles must therefore be omitted from structured counts and described in evidence notes. The z-axis module is an axis-only physical input, for which the schema has no axis control item; it currently uses the closest generic analog control representation. Rotary selectors can already record positions and push; levers can record push; triggers support flip and bidirectional actions. No unsupported schema-limit claim remains in the corrected notes.
