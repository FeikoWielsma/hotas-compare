## Schema limitations and unresolved facts

The schema can represent analog axes and discrete rotary selectors, but lacks a general physical multidirectional joystick/paddle subtype; existing rocker/rotary categories are imperfect descriptions for some devices. Viper Panel’s virtual button aggregate cannot be reliably divided into standalone button versus switch input totals from product marketing alone. Exact physical switch position/action types for the Warthog throttle, TCA Yoke, and Viper controls need visual/manual mapping inspection. No evidence found to establish that the Warthog base has no physical controls, so empty controls must not be read as verified absence.
