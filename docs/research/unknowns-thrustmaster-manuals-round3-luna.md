# Thrustmaster legacy catalog unknowns — round 3 (Luna)

Checked 2026-10-20. Scope: ten Thrustmaster legacy component records only. I read the catalog unknowns inventory and the previous two Thrustmaster/MOZA research rounds first. Sources are manufacturer product pages and official support PDFs; no retailer measurements or cross-model projection was used.

## Method and diagram review

Downloaded the official PDFs to a temporary directory and rendered the English pages for visual inspection. The inspected diagrams include the T.16000M feature/backlight page, TWCS PC generic mapping, TCA Airbus quadrant feature and mapping diagrams, TCA Sidestick feature diagram, TCA Boeing quadrant feature/mapping diagrams, TCA Boeing yoke feature diagram, Warthog joystick/throttle inventory, and TPR tension adjustment. The images show physical control locations and clarify which numbers are hardware controls versus mapped input events.

I did not add virtual throttle/reverser/detent events as separate physical controls. In particular, the TCA Airbus quadrant manual describes detent events as virtual buttons, and the Sidestick manual identifies a virtual button on the throttle travel. A control's light, push, or latching behavior remains unknown when the diagram or text does not establish that physical property. The T.16000M manual describes center-stick backlighting, which does not establish that its separate grip/base buttons are backlit.

## Findings left unresolved

- The TCA Boeing yoke official product page lists 6.7 kg, but its manual p. 3 warning icon lists 3.8 kg. Weight stays blank until the discrepancy is resolved from a matching official component specification.
- The reviewed diagrams show logical button identifiers and aggregate button totals, but do not establish every separate physical click, backlight state, or switch return behavior. These optional control properties remain unknown unless named explicitly.
- TPR pedal-angle adjustment changes travel; the official source does not define one total axis throw in degrees, so `hardware.throw_deg` remains unknown.
- This pass did not edit Sol-R records, bundles, HOTAS 4/X, or records outside the listed ten.
