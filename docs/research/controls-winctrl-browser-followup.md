## Schema limits and follow-up

The controls schema cannot name a power button distinct from a generic button. It also cannot encode an asymmetric multi-position switch with one side momentary, so the ICP WARN RESET mechanism is identified in its label and notes. For Orion 2 throttle guide rails, the array records one installed detent system, not all included alternatives. Hat directions and pushability remain omitted where official descriptions do not state them. All source/model caveats above are preserved in each YAML `controls_evidence` note where they affect the record.
