# Honeycomb Alpha original vs XPC: shared controls

## Findings

Honeycomb’s current product pages describe the same flight-control layout for the original Alpha and Alpha XPC: a main/master, alternator and avionics switch; lighting switches; a five-position ignition switch; four handle-mounted two-way rockers (two vertical on the left and two horizontal on the right); one eight-way POV/hat switch; and four handle buttons (two per handle, including push-to-talk). Honeycomb’s XPC page explicitly gives this layout, and the original page’s handle descriptions break out the same left/right placement. The XPC statement “three buttons, and a push-to-talk button” is consistent with four physical handle buttons total. [Original Alpha](https://flyhoneycomb.com/products/alpha-flight-controls) · [Alpha XPC](https://flyhoneycomb.com/products/alpha-flight-controls-xpc)

Honeycomb’s marketing copy calls the panel controls “main, alternator, avionics, and light switches” without a numeric lighting-switch count. The product-panel diagram supplied for this comparison shows four master/avionics panel switches and five lighting switches; record those physical panel quantities from that diagram rather than treating Honeycomb’s plural wording as a count. Both product pages describe the five-position ignition switch.

The XPC product image shows an additional four-button Xbox navigation cluster on the base. Count these as four physical Xbox navigation buttons (the existing YAML value is 4), not as a claim about joystick input/button IDs. The product pages distinguish platform support: original Alpha lists PC and Mac; XPC lists PC, Mac, Xbox One, and Xbox Series X|S. [XPC product page and images](https://flyhoneycomb.com/products/alpha-flight-controls-xpc)

The XPC’s stated hardware upgrade is Hall-effect sensing: Honeycomb describes “upgraded Hall Effect Sensors” and a 180° yoke rotation. This is the advertised sensor upgrade; it does not change the shared switch/handle control layout above. [XPC product page](https://flyhoneycomb.com/products/alpha-flight-controls-xpc)

## Source note

Honeycomb’s current [downloads page](https://flyhoneycomb.com/pages/downloads) lists MSFS 2024 “Alpha Lite” documentation, but no Alpha XPC control map. Therefore, this note reports physical controls from Honeycomb’s product descriptions and product imagery, not inferred input numbers or a button-ID mapping.
